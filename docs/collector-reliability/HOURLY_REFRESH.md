# Automatic market refresh

The public web collector now starts one immutable source selection each hour at minute 15 UTC, with retries at minutes 20 and 25. Its existing two-minute worker drains that selection. It rotates through eight configured public query themes, including funding, acquisitions, products and deployments. Each query selects up to four RSS articles. A full new day can select at most 96 articles. The transition-day ceiling also preserves the former daily batch: 32 feeds / 128 items, 64 feed attempts / 256 item attempts. Each task retains its two-attempt limit, one active lease, provider cooldown and durable dispositions. Sources remain bounded; this is not a claim of complete market coverage.

Validated public RSS headlines enter `/api/market-source-reports` immediately and appear in Recent source reports on Latest updates. They are explicitly unverified and ineligible for financial totals. The table retains publisher links and RSS dates, with unknown dates labelled. It never reads private Gmail/ChatGPT text. The page checks every 30 seconds, aborts stalled requests after 10 seconds and retains the previous data during an outage. Source verification and the existing independent SQL evidence gates still decide whether financing/M&A records enter approved activity totals.

Gmail continues its existing daily selection every two minutes until complete or its 24-request ceiling is reached, rather than stopping after three requests. Network and model calls have finite deadlines. Each committed message/rejection is checkpointed independently, so a later failure cannot replay a completed prefix. Retrying an existing queue ID cannot overwrite a previously reviewed disposition. Historical failed runs and all original task/budget history remain intact.

Activation requires the reviewed backend and matching frontend, then the generated migrations: hourly_market_refresh_reliability, automatic_public_source_reports, source_report_relevance and gmail_continuation_jitter. Repository migration versions match the actual applied production history. They reuse the current project and scheduler credential; no credential is copied or exposed. Check active cron configuration, a hosted collection task, the source-report API and the already-open browser. Check Gmail's saved selection reaches its genuine terminal state. Overall health still includes unrelated/private review and ecosystem coverage; do not describe legitimate holds or missing market coverage as resolved merely because refresh works.

Tyrant's separate draft remains unactivated until its actual producer connection is authorized and verified. Public RSS collection does not imply access to Tyrant's private conversation.
